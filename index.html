    그림을 누르면 크게 볼 수 있어요. 두 손가락으로 벌려 확대할 수도 있어요.

    게임기 조작법

    대기화면(점수판 PLAy)에서 아무 버튼이나 눌렀다 떼면 게임이 시작돼요.

    난이도 바꾸기

    1. 빨강+파랑함께 5초 꾹

      대기화면에서 눌러요. 점수판 - -- --- ---- 다음 SEt

    2. 노랑누를 때마다 바뀌어요

      L-1 → L-2 → L-3 (LED 막대도 1~3칸)

    3. 초록저장

      donE 다음 대기화면으로 돌아가요

    • 빨강 저장하지 않고 취소
    • 20초 동안 아무것도 안 누르면 저장 없이 자동으로 빠져나와요

    선생님·도우미만 설정 메뉴에서 파랑 3초 → 지금 고른 난이도의 최고점 지우기 CLr

    난이도별 차이

    항목L-1초급L-2중급L-3고급
    나오는 색빨·노·파

    잘못 쏘면제한 없음0.3초 못 쏨0.6초 못 쏨

    순위표는 난이도 구분 없이 점수만 비교해요. 기록할 판은 선생님이 정한 난이도로 해요.

    한 판의 흐름

    1. 시작아무 버튼을 눌렀다 떼면 3, 2, 1, GO
    2. 게임다가오는 빛을 같은 색 버튼으로 쏘기 (최대 90초)
    3. 끝생명이 다 떨어지거나 90초가 지나면 End, 이어서 내 점수가 깜빡여요
    4. 다음 판2.5초 뒤 아무 버튼. 12초 동안 안 누르면 대기화면으로

    연결 확인 (점검 모드)

    1. 들어가기대기화면에서 노랑+초록 함께 5초
    2. 확인버튼을 하나씩 누르면 LED 전체가 그 색으로 바뀌고 소리가 나요. 점수판 b-1~b-4
    3. 나가기노랑+초록 함께 3초

    다른 색이 뜨면 그 버튼 선이 다른 줄에 꽂힌 거예요. 회로카드 표와 맞춰 보세요.
